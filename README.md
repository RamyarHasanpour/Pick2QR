# Pick2QR

A lightweight desktop application for generating and auto-saving QR codes, built with Python and CustomTkinter.

## Features

- Generate QR codes instantly from any text or URL.
- Auto-detects available local drives to save images (creates a `Pick2QR` directory).
- Dark/Light mode toggle.
- Live preview of the generated QR code on the screen.

## Requirements

Python 3.8+ and the following dependencies:

```bash
pip install customtkinter qrcode[pil] Pillow
```

## How to Run

1. Clone this repository or download the source code.
2. Open a terminal in the project directory.
3. Run the script:

```bash
python main.py
```
